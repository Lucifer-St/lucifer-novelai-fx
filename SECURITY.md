# Security reports

Do not post vulnerabilities, credentials, private prompts, local paths, cookies, logs, or upstream response bodies in a public Issue.

The application does not upload feedback automatically. Its Release Center creates a local, structured preview from allowlisted diagnostic fields. Review that preview before copying or exporting it.

A private security-reporting channel will be documented here only after the real public repository exists and GitHub private vulnerability reporting has been enabled and verified. No placeholder URL or email address is provided. Until then, keep sensitive evidence local rather than opening a public report.
