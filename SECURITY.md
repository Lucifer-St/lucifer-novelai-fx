# Security reports

Report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/Lucifer-St/lucifer-novelai-fx/security/advisories/new).

Do not post credentials, private prompts, local paths, cookies, logs, or upstream response bodies in public Issues. Share only the evidence necessary to reproduce the issue. If the private channel is unavailable, keep sensitive evidence local rather than opening a public report.

The application does not upload feedback automatically. Its Release Center creates a local preview from allowlisted diagnostic fields. Review that preview before copying or exporting it. Update checks may contact GitHub automatically and can be disabled; downloading and installing an update require explicit user actions.
