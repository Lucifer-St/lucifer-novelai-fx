# 分享版范围

当前公开源码对应 Windows 分享版 1.8.0，代码采用 MIT；第三方依赖和美术条款见 SOURCE-LICENSE.md。

| 范围 | Windows 分享版 |
|---|---|
| 连接 | 使用者自行配置 NovelAI 官方接口或兼容网关，无作者凭据或固定私人服务 |
| 提示词 | 经典标签布局、合并滚动布局、独立折叠与自适应角色编辑框 |
| 资料库 | 随包 Claire、Noire、Rena 三张卡；不附完整 preset 种子，自建资料保留 |
| 皮肤 | 包含 Teresa、两款 Precure 等八款工作台皮肤，加载画面独立选择 |
| 图库 | Danbooru 浏览状态在会话内保留，支持刷新与跳页；法典独立存储 |
| 本地工具 | CLI / MCP、原生文件夹选择器、目录快捷打开、备份与图片隐私导出 |
| 更新 | 可关闭的自动版本检查；明确点击后下载、校验、安装和重启 |
| 助手扩展 | 折叠 LLM 预留入口；不含个人版 Grok / ComfyUI 集成 |
| Android | 原生源码冻结在 1.1.1 / versionCode 3，与当前 Windows 前端接口不兼容；不能直接拼装为可用的新 Android 应用 |

两个版本分别保存配置与用户数据。共享功能逐模块维护，不能整目录覆盖或把个人版凭据、历史、素材库带入分享版。Android 的接口差异和构建限制见 ANDROID-SOURCE.md。
