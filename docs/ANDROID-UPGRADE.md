# Android 1.13.0 更新记录与验证边界

本次恢复 Android 维护：以分享版 1.12.2 为功能基线，保留应用 ID、系统密钥别名、userdata 目录和旧历史格式。开发在独立分支进行，不改个人版。多语言只研究，不实现。

升级范围：当前主题与编辑器、V4.5/V5 模型、参考图、图库检索/收藏/标签/对比/导出、历史分页、自动输出开关、重复生成防护、资料备份兼容、更新反馈与手机布局。生成测试只用本地合成服务。

Android 保留系统文件选择器、相册、分享与前台生成服务。Windows 托盘、进程退出、stdio Agent 与 ZIP 安装不适用于 Android。APK 更新由用户在系统安装器确认，不请求静默安装权限。

已验证：233 项共用单元/后端测试、35 项 Android 原生及真实 WebView 检查、8 项共享桌面/窄屏浏览器回归。Android 检查覆盖 11 套主题、实际提示词编辑和点击合成生成、流式和逐张任务、V4.5 报价、编码缓存与账本、收藏 PATCH、保护状态变更、删除/恢复、备份去重、分页、系统相册和分享。未使用真实 Key 或付费上游。

JDK 21 / SDK 36 的 Debug、Release 构建及 release lint 通过（0 错误；现有依赖和平台建议仍有警告）。运行验证使用 Android 15 / API 35 x86_64 模拟器。Debug 使用独立 QA 身份；正式包沿用原应用 ID 和原签名证书。编译与模拟器通过不代表真机、Android 10、所有 WebView 版本或第三方网关验收。

生成图库通过原生历史扫描查询，不引入 Windows SQLite FTS。部分删除一组图片时，共享原始响应保留；系统目录中的外部导出始终保护。七天回收站和可选数量上限只在应用运行且空闲时处理。Windows 1.12.2 安装包和旧 Releases 保留。

正式签名覆盖升级已在全新 Android 15 模拟器完成：安装原 1.1.1 APK，输入无凭据的测试草稿，再以原签名覆盖安装 1.13.0 / versionCode 4；新版显示正确公告、模型选择与费用徽标，旧提示词仍保留。该样本证明安装身份与浏览器草稿保留，不替代真实用户完整图库及凭据迁移验收。
